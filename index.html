Password & passphrase

Real words, real entropy —
not a hardcoded sample.

password is character-based with a configurable charset (--exclude-ambiguous drops 0O1lI|). passphrase is diceware-style, drawn from the actual EFF large wordlist — 7776 words, embedded at compile time.

Both print entropy in bits and a colored strength meter alongside the result. --save <label> pipes it straight into CyberVault; --raw gives bare output for scripts.

keysmith
generate
$ keysmith passphrase --words 6 --save github

timber-holster-planet-ozone-velvet-cactus
~101 bits (Very Strong)
piped into cybervault add "github"

$ keysmith password --length 24 --exclude-ambiguous --copy
kX8#mQ2vR&pL9nW4tZ6cJ3h
~140 bits (Very Strong)
copied to clipboard
Hash vs. pwhash — not the same thing

Fast checksums and
slow password storage, kept apart.

hash is fast general-purpose checksumming (SHA-256/512, BLAKE3) — correct for verifying a file wasn't tampered with, wrong for storing a password, since fast hashes make offline brute-forcing cheap.

pwhash is Argon2id specifically — deliberately slow, memory-hard, and salted. Password is a hidden terminal prompt that refuses piped input by design, never a CLI argument.

keysmith hash / pwhash
checksum
$ keysmith hash --file release.tar.gz
sha256  9f86d081884c7d659...
blake3  af1349b9f5f9a1a6a...

$ keysmith pwhash
Password: ************
$argon2id$v=19$m=19456,t=2,p=1$...

Get Keysmith running

One command — downloads, verifies the checksum, installs to ~/.local/bin.

>_ curl -fsSL https://raw.githubusercontent.com/darkstardevx/keysmith/main/install.sh | sh

Installs keysmith. Works standalone — CyberVault is only needed for --save.
